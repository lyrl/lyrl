### 🙋 关于我

一个把 **AI Agent 当作工程问题** 来做的开发者。比起「Prompt 写得多妙」，我更关心 Agent 跑在什么样的 Harness 里、上下文怎么喂、记忆怎么存、工具怎么接、效果怎么验收、成本和安全怎么兜底。

日常习惯是**边读边造**：自建 RSS + AI 摘要/翻译的阅读流水线，长期跟踪 Agent 工程、架构与开发者体验，至今攒下 1800+ 篇星标文章，沉淀进 Obsidian；看到好的思路就动手 fork、改造、提 PR。

### 🧩 我的做事风格

<ul>
<li>🔧 <b>工程优先</b>：相信 best practices 和可复现的流程，Agent 也要有测试、有观测、有回滚</li>
<li>📏 <b>先验证再相信</b>：新框架、新 Skill 都想先拿数据证明它真的有用</li>
<li>🏠 <b>自托管 & 开源优先</b>：能自己部署的就自己部署，能贡献回社区的就提 PR</li>
<li>⚙️ <b>自动化一切</b>：重复两次以上的事就写脚本，重复三次就交给 Agent</li>
<li>🤔 <b>关心「为什么」</b>：爱读软件哲学和职业思考，不只追新工具，也想清楚它改变了什么</li>
</ul>
